# 🚀 Event Page - Quick Reference Card

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `N` | Create new event |
| `M` | Month view |
| `W` | Week view |
| `D` | Day view |
| `A` | Agenda view |
| `L` | List view |
| `/` | Search events |
| `Esc` | Close dialogs |
| `?` | Show shortcuts help |

## 📅 Calendar Views

### Month View (M)
Traditional calendar grid showing all events

### Week View (W)
7-day hourly schedule from 7 AM to 9 PM

### Day View (D)
24-hour detailed schedule for one day

### Agenda View (A)
Chronological list of next 20 upcoming events

### List View (L)
All events with search/filter options

## 🔄 Creating Recurring Events

1. Click "Create Event" (or press `N`)
2. Fill in event details
3. Toggle **"Recurring Event"** switch
4. Select pattern:
   - **Daily** - Every N days
   - **Weekly** - Specific days of week
   - **Monthly** - Every N months
5. Set recurrence end date
6. Save

## 🔔 Setting Reminders

1. In event form, find "Reminders" section
2. Click "Add Reminder" for each reminder
3. Choose type:
   - 📱 **Telegram** - Bot notification
   - 📧 **Email** - Email alert
   - 🔔 **In-App** - Browser notification
4. Set time before event:
   - 15 min, 30 min, 1 hr, 2 hr
   - 1 day, 2 days, 1 week

**Tip:** Add multiple reminders for important events!

## ⚠️ Conflict Handling

**What happens:**
1. System detects conflicts automatically
2. Your event enters queue
3. You get queue position
4. Receive notifications when date available

**Your Options:**
- Wait in queue (FIFO)
- Choose different date
- Contact conflicting party
