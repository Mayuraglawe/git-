## 📖 Full Workflow Example

### Creating a Workshop Event

**Step-by-Step:**

1. **Click "Create Event" Button**
   ```
   [+ Create Event]
   ```

2. **Select Event Type**
   ```
   Event Type: Workshop ▼
   ```

3. **Type Title - See Suggestions**
   ```
   Event Title: [work_____]
   
   Suggestions:
   → Workshop on
   → Technical Workshop:
   → Hands-on Workshop:
   
   Click: "Workshop on"
   Result: "Workshop on "
   ```

4. **Complete Title**
   ```
   Event Title: [Workshop on Machine Learning]
   ✓ First letter auto-capitalized!
   ```

5. **Add Description**
   ```
   Description: [introduction to ML concepts]
   Auto: "Introduction to ML concepts" ✓
   ```

6. **Select Venue - Use Autocomplete**
   ```
   Venue: [aud_____]
   
   Suggestions:
   → Auditorium
   
   Click: "Auditorium"
   ```

7. **Fill Other Details**
   ```
   Start Date: [Select date]
   Start Time: [10:00]
   End Time: [12:00]
   ```

8. **Contact Person - Auto-Capitalize**
   ```
   Contact Person: [dr. smith]
   Auto: "Dr. smith" ✓
   ```

9. **Submit!**
   ```
   [Create Event] ← Click
   
   ✅ Event created
   📱 Telegram notification sent
   🔄 Queue updated (if needed)
   ```

### Tip 1: Select Event Type First
```
✅ GOOD:
1. Select "Workshop" 
2. Type title → Get Workshop-specific suggestions

❌ SKIP:

```
Type ANY part of the suggestion:

"tech" matches "Technical Workshop:"

```

```
After creating events, suggestions include YOUR previous titles:

## ❓ FAQ

### Q1: Why don't I see suggestions?
**A:** Make sure you've selected an Event Type first! Suggestions are context-aware.

### Q2: Can I still type manually?
**A:** Yes! Suggestions are optional. Type normally if you prefer.

### Q3: How do I close the suggestions?
**A:** Click outside, press ESC, or just start filling other fields.

### Q4: Are suggestions from my events or global?
**A:** Both! You see:
- Pre-defined templates (e.g., "Workshop on")
- Your department's previous events
- All public events (if admin)

### Q5: Does it work on mobile?
**A:** Yes! Touch to select suggestions works perfectly.

### Q6: Can I add my own templates?
**A:** Currently no, but it's planned for future updates!

## 🐛 Troubleshooting

### Issue 1: No Suggestions Appearing
```
Check:
□ Event Type is selected?
□ Typing at least 1 character?
□ Field has focus (cursor blinking)?

Fix:
1. Click the field again
2. Delete text and retype
3. Try selecting a different Event Type
```

### Issue 2: Suggestions Not Clickable
```
Check:
□ Using mouse/trackpad correctly?
□ Browser zoom level normal (100%)?

Fix:
1. Refresh page (F5)
2. Clear browser cache
3. Try keyboard (↓ arrow + Enter) - coming soon!
```

### Issue 3: Capitalization Not Working
```
Check:
□ Typing in supported field (Title, Description, Venue)?
□ Starting from beginning of text?

Fix:
1. Delete text completely
2. Type again from start
3. First letter will capitalize
```
