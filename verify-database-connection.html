🔐 Environment Configuration

📌 Required Environment Variables

Server-side:
• SUPABASE_URL - Database URL
• SUPABASE_SERVICE_ROLE_KEY - Admin access key

Client-side:
• VITE_SUPABASE_URL - Database URL (public)
• VITE_SUPABASE_ANON_KEY - Anonymous access key (public)

⚠️ Security Note

The service role key should NEVER be exposed to the client-side.
Only use it in server-side code for admin operations.
