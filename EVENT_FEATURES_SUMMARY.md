## 🚀 Quick Start

### Using Quick Add
```
Press Ctrl+Q → Type "Workshop tomorrow 2pm" → Create
```

### Using Templates
```
Click template card → Customize → Submit
```

### Managing Tasks
```
Press Ctrl+T → Create task → Link to event
```

### Setting Working Hours
```
Press Ctrl+H → Configure schedule → Save
```

### Sharing Events
```
Open event → Share → Add email → Set access level
```
