# 🚀 Indian Holiday Calendar - Quick Start Guide

## ✨ Feature Summary

**NEW**: Indian Holiday Calendar is now live in your Smart Classroom application!

### What's New?
- 🇮🇳 **Indian Holidays**: All 2025-2026 national & religious holidays
- 🔴 **Visual Indicators**: Holidays in RED background, Sundays in RED text
- 📅 **Interactive Calendar**: Click any date to see holiday details
- ⏰ **Countdown Timer**: See upcoming holidays with days remaining
- 📊 **Monthly Stats**: Holiday breakdown by type and category

---

## 🎯 How to Access

### Option 1: Navigation Menu
1. Look at the **left sidebar**
2. Click **"🇮🇳 Holidays"** link (second item from top)
3. View the full calendar page

### Option 2: Dashboard
1. Go to the **Dashboard** (home page)
2. Scroll to **Quick Actions** section
3. Click **"🇮🇳 Holiday Calendar"** card
4. View the full calendar page

### Option 3: Direct URL
Navigate to: `http://localhost:8080/calendar-demo`

## 📅 Using the Calendar

### 1. **View Holidays**
- **Current Month**: Calendar displays current month by default
- **Navigate Months**: Use ◀ ▶ arrows to change months
- **Select Date**: Click any date to see details below calendar

### 2. **Holiday Information**
When you click a holiday date, you'll see:
- 🕉️ **Festival Icon** (Hindu, Muslim, Christian, etc.)
- **Holiday Name** (e.g., "Diwali")
- **Description** (e.g., "Festival of Lights")
- **Type Badge**: National or Restricted
- **Category Badge**: Hindu, Muslim, Christian, etc.

### 3. **Upcoming Holidays (Right Panel)**
Shows next 5 holidays with:
- **Date box** color-coded by category
- **Holiday name** with icon
- **Description** 
- **Countdown**: "Today", "Tomorrow", or "Xd" (days)
- **Badges**: National/Restricted + Category

### 4. **Monthly Statistics (Top)**
Four stat cards showing:
- 📊 **Total Holidays**: All holidays this month
- 🇮🇳 **National Holidays**: Govt office closures
- 🔸 **Optional Holidays**: Restricted holidays
- ☀️ **Sundays**: Weekly offs count

## ❓ FAQs

**Q: How are holidays determined?**
A: Based on Government of India official calendar and trusted sources like RBI holiday list.

**Q: Are all states' holidays included?**
A: Currently shows national holidays. Regional holidays coming soon.

**Q: Can I add custom holidays?**
A: Not yet. Feature planned for future updates.

**Q: Why some holidays show as "Restricted"?**
A: These are optional holidays where 2-3 can be chosen by employees.

**Q: How accurate are festival dates?**
A: Very accurate. Based on official Hindu/Islamic/Christian calendars.

**Q: Will calendar update next year?**
A: Yes. Data updated annually with official announcements.

**Q: Can I export this calendar?**
A: Export feature coming in next update (PDF/ICS format).

**Q: Does it work offline?**
A: No, requires internet connection for full functionality.
