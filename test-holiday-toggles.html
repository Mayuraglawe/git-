🎚️ Holiday Toggle Controls Test Guide

Complete testing guide for Show Holidays and Google Calendar toggle switches

📋 Overview

The Events page now includes two toggle switches that control how holidays are displayed in the calendar view. These controls allow users to customize their calendar experience by showing/hiding holidays and choosing between local data and Google Calendar integration.

⭐ Show Holidays Toggle

Controls visibility of all holidays (including Indian holidays and Sundays) in the calendar grid. When enabled, holidays appear with colored backgrounds and star icons.

📅 Google Calendar Toggle

Switches between local Indian holiday data and Google Calendar API integration. Requires API key configuration. Disabled when "Show Holidays" is off.

🎨 Color-Coded Holidays

Different holiday types have distinct colors: National (Orange), Religious (Purple), Cultural (Green), and Sundays (Red) for easy identification.

📍 Where to Find the Toggles

🔍 Navigation Steps

  1. Open the application at http://localhost:8081/
  2. Navigate to the Events page from the sidebar menu
  3. Click on the Calendar tab (if in List view)
  4. Look at the header section, next to the Calendar/List toggle
  5. You'll see two switches with labels:
    • Show Holidays - Controls holiday visibility
    • Google Calendar - Controls data source

📸 Expected UI Location

The toggles appear in the header, between the Calendar/List tabs and the "Create Event" button

[Header] → [Calendar/List Tabs] → [Show Holidays Switch] → [Google Calendar Switch] → [Create Event Button]

✅ Manual Testing Steps

1️⃣ Test "Show Holidays" Toggle - ON State

  1. Navigate to Events page → Calendar view
  2. Ensure "Show Holidays" toggle is ON (default state)
  3. Observe the calendar grid for October 2025
  4. Verify you see:
    • ⭐ Star icons on holiday dates (Oct 2, 3, 20, 24, 27)
    • 🌟 Red background on all Sundays (5th, 12th, 19th, 26th)
    • 🎉 Colored backgrounds on national/religious/cultural holidays
    • Holiday names when clicking on dates
  5. Check the calendar header shows "Indian holidays & Sundays included"

2️⃣ Test "Show Holidays" Toggle - OFF State

  1. Click the "Show Holidays" toggle to turn it OFF
  2. Observe the calendar grid immediately
  3. Verify:
    • ❌ No star icons on any dates
    • ❌ No red backgrounds on Sundays
    • ❌ No colored backgrounds on holiday dates
    • ❌ Holiday information doesn't appear in date details
    • ✅ Only events are visible (if any)
  4. Notice the "Google Calendar" toggle becomes disabled

3️⃣ Test "Google Calendar" Toggle

  1. Turn "Show Holidays" toggle ON first
  2. Click "Google Calendar" toggle to turn it ON
  3. Observe the behavior:
    • ⏳ Calendar may show loading indicator briefly
    • If API key is configured: External holiday data fetches
    • If no API key: Falls back to local Indian holidays data
    • Check calendar header for "Google Calendar" indicator
  4. Turn toggle OFF to revert to local data only
  5. Verify holidays still display (from local data)

4️⃣ Test Toggle Interaction

  1. Verify "Google Calendar" toggle is disabled when "Show Holidays" is OFF
  2. Turn "Show Holidays" ON → "Google Calendar" toggle becomes enabled
  3. Test rapid toggling doesn't cause errors
  4. Check browser console for any error messages
  5. Switch to List view → Toggles should disappear
  6. Switch back to Calendar view → Toggles reappear

✨ Expected Behavior

✅ When Show Holidays is ON

  • Calendar Grid: Holidays visible with colored backgrounds
  • Date Headers: Star icons (⭐) appear on holiday dates
  • Sundays: Red background (bg-red-50 border-red-200)
  • National Holidays: Orange background (bg-orange-50 border-orange-200)
  • Selected Date Panel: Shows holiday information first, then events
  • Header Text: "Indian holidays & Sundays included" message visible
  • Loading State: "(loading...)" appears briefly when fetching holidays

✅ When Show Holidays is OFF

  • Calendar Grid: No holiday indicators or backgrounds
  • Date Headers: No star icons
  • Selected Date Panel: Only events shown, no holiday information
  • Google Calendar Toggle: Disabled and grayed out
  • Performance: No holiday data loading, faster rendering

✅ When Google Calendar is ON

  • Data Source: Attempts to fetch from Google Calendar API
  • API Key Check: Uses VITE_GOOGLE_CALENDAR_API_KEY env variable
  • Fallback: If API fails or no key, uses local Indian holidays
  • Header Indicator: Shows "• Google Calendar" in header text
  • Combined Data: Merges Google data with local holidays (local priority)

🔧 Implementation Details

Code Implementation

Events.tsx - Toggle Controls

// State variables
const [showHolidays, setShowHolidays] = useState(true);
const [useGoogleCalendar, setUseGoogleCalendar] = useState(false);

// Toggle controls (only visible in calendar view)
{activeView === 'calendar' && (
  <div className="flex items-center gap-3 border-l pl-4">
    <Switch
      id="show-holidays"
      checked={showHolidays}
      onCheckedChange={setShowHolidays}
    />
    <Label htmlFor="show-holidays">Show Holidays</Label>
    
    <Switch
      id="google-calendar"
      checked={useGoogleCalendar}
      onCheckedChange={setUseGoogleCalendar}
      disabled={!showHolidays}
    />
    <Label htmlFor="google-calendar">Google Calendar</Label>
  </div>
)}

// Pass props to EventCalendar
<EventCalendar
  events={calendarEvents}
  onEventClick={handleEventClick}
  onDateClick={handleDateClick}
  onCreateEvent={handleCreateEvent}
  showHolidays={showHolidays}
  useGoogleCalendar={useGoogleCalendar}
/>

EventCalendar.tsx - Holiday Loading

// Load holidays when showHolidays or useGoogleCalendar changes
useEffect(() => {
  if (!showHolidays) return;

  const loadHolidays = async () => {
    setIsLoadingHolidays(true);
    try {
      const year = currentDate.getFullYear();
      const month = currentDate.getMonth() + 1;
      
      if (useGoogleCalendar) {
        const holidayData = await holidayService.getCombinedHolidays(year, month);
        setHolidays(holidayData);
      } else {
        const holidayData = holidayService.getHolidaysForMonth(year, month);
        setHolidays(holidayData);
      }
    } catch (error) {
      console.error('Error loading holidays:', error);
      // Fallback to local holidays
      const fallbackHolidays = holidayService.getHolidaysForMonth(year, month);
      setHolidays(fallbackHolidays);
    } finally {
      setIsLoadingHolidays(false);
    }
  };

  loadHolidays();
}, [currentDate, showHolidays, useGoogleCalendar]);
